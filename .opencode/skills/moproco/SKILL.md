# Moproco

This project uses Moproco DSLs. Generated code is marked with `@generated by Moproco` — do not edit.

## Workflow — use these tools INSTEAD of reading files yourself

1. **Implement TODOs**: Call `moproco_implement_todos` — returns the full source of every service and test file that has TODO markers. Implement the TODOs directly.

2. **Implement a story**: Call `moproco_story_context` with the story name — returns the DSL definitions, generated service, controller, and test files. Implement the business logic.

3. **Regenerate code**: Call `moproco_generate` after changing DSL files.

## Rules

- Do NOT read DSL files or generated files yourself. Use the tools above — they return the exact contents you need.
- Files with `@generated by Moproco` are auto-generated. Edit the DSL files and regenerate instead.
- Service stubs have `// TODO: implement` markers. Fill in the business logic.
- Test stubs have `// TODO` markers. Fill in the assertions.
